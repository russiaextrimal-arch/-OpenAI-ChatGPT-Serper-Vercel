НАЧНИ ЗДЕСЬ — навык Яндекс Алисы с OpenAI API

Для ответов навыка используется OpenAI API. Подписка ChatGPT Plus/Pro не включает оплату API: создайте API-ключ и настройте биллинг на платформе OpenAI.

1. Загрузите содержимое этой папки в свой GitHub-репозиторий. Сохраните папку api и файл api/index.js внутри неё.
2. В Vercel нажмите Add New… → Project и импортируйте свой репозиторий.
3. В Project → Settings → Environment Variables добавьте:
   OPENAI_API_KEY — секретный ключ https://platform.openai.com/api-keys
   SERPER_API_KEY — ключ Serper https://serper.dev (необязательно, только для поиска в интернете)
   OPENAI_MODEL — необязательно, по умолчанию gpt-6-astra
   Для переменных выберите Production.
4. После добавления переменных откройте Deployments, нажмите Redeploy и дождитесь Ready.
5. Откройте Settings → Domains, скопируйте домен Vercel, добавьте /api и укажите этот адрес как Webhook URL в Яндекс Диалогах.
6. При необходимости включите «Использовать хранилище данных в навыке», чтобы сохранять контекст между репликами.

ПРОВЕРКА

Откройте раздел «Тестирование» в консоли Яндекс Диалогов и задайте навыку вопрос. Можно также запустить его голосом, если он доступен аккаунту.

ЕСЛИ НЕТ ОТВЕТА

Проверьте API-ключ, биллинг и лимиты OpenAI API, переменные Production и Webhook URL. После изменения ключей сделайте Redeploy. Не отправляйте ключи в чаты и не загружайте их в GitHub.

Node.js нужен только для разработки; для обычной настройки через GitHub/Vercel устанавливать его не требуется.
