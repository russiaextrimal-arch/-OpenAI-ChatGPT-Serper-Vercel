# Яндекс Алиса + OpenAI (ChatGPT) + Serper на Vercel

Готовый webhook для навыка Яндекс Алисы. Ответы генерирует OpenAI API, а Serper по желанию добавляет результаты поиска в интернете для актуальных вопросов. Код не требует правок: разверните репозиторий в Vercel и добавьте API-ключи.

> OpenAI API оплачивается отдельно от подписки ChatGPT Plus/Pro. Для работы навыка нужен API-ключ и включённый биллинг на платформе OpenAI.

## Развёртывание через GitHub и Vercel

1. Загрузите этот проект в свой GitHub-репозиторий (или используйте Fork исходного шаблона и замените его файлы содержимым этого проекта).
2. Откройте [Vercel Dashboard](https://vercel.com/dashboard) и выберите **Add New… → Project**.
3. Импортируйте свой репозиторий и нажмите **Deploy**.
4. В проекте Vercel откройте **Settings → Environment Variables** и добавьте переменные для окружения **Production**:
   - `OPENAI_API_KEY` — секретный ключ из [OpenAI API keys](https://platform.openai.com/api-keys).
   - `SERPER_API_KEY` — ключ из [Serper](https://serper.dev), если нужен интернет-поиск.
   - `OPENAI_MODEL` — необязательно; по умолчанию `gpt-6-astra`. Укажите модель, доступную в вашем OpenAI API-проекте.
5. После сохранения переменных откройте **Deployments**, нажмите **Redeploy** на последнем Production-развёртывании и дождитесь статуса **Ready**.
6. В **Settings → Domains** скопируйте домен Vercel и добавьте `/api`, например `https://YOUR-PROJECT.vercel.app/api`.
7. В настройках навыка в Яндекс Диалогах вставьте полный адрес в поле **Webhook URL**.
8. Включите **Использовать хранилище данных в навыке**, чтобы сохранять контекст между репликами.

Названия разделов Vercel могут немного отличаться. Используйте собственный домен проекта.

## Если вы скачали ZIP

1. Распакуйте архив.
2. В своём GitHub создайте репозиторий и загрузите в него содержимое этой папки, включая `api/index.js`.
3. Импортируйте репозиторий в Vercel и выполните шаги настройки выше.

## Ключи и безопасность

- `OPENAI_API_KEY` нужен для ответов модели. Создайте ключ на платформе OpenAI и задайте платёжные лимиты проекта.
- `SERPER_API_KEY` включает интернет-поиск. Если переменная не задана, обычные ответы модели работают без поиска.
- `OPENAI_MODEL` необязателен. По умолчанию используется `gpt-6-astra`; можно указать другую модель, доступную вашему API-проекту.

Храните ключи только в **Vercel → Settings → Environment Variables**. Не добавляйте их в исходный код, GitHub, README, Яндекс Диалоги или сообщения. Если ключ стал доступен посторонним, отзовите его и создайте новый.

## Как проверить навык

1. Укажите свой Webhook URL в Яндекс Диалогах; адрес должен заканчиваться на `/api`.
2. Сделайте навык приватным и доступным для тестирования.
3. Откройте раздел **Тестирование** в консоли Яндекс Диалогов или запустите навык голосом с аккаунта, имеющего доступ.
4. Задайте вопрос и проверьте ответ.

## Если навык не отвечает

1. Проверьте `OPENAI_API_KEY`, `SERPER_API_KEY` и выбранное окружение **Production**.
2. После изменения переменных выполните **Redeploy** и дождитесь статуса **Ready**.
3. Убедитесь, что Webhook URL использует ваш домен Vercel и заканчивается на `/api`.
4. Если API отвечает ошибкой лимита, проверьте биллинг и лимиты OpenAI API-проекта. Подписка ChatGPT не заменяет API-биллинг.
5. Посмотрите логи последнего развёртывания Vercel. Удалите секретные данные перед передачей логов кому-либо.

## Ограничение времени ответа

Яндекс Диалоги ожидают ответ примерно за 4,5 секунды. Поэтому поиск и запрос к модели имеют короткие тайм-ауты. Если внешний сервис отвечает медленно, навык вернёт короткое сообщение с просьбой повторить вопрос. Это уменьшает риск тайм-аута, но не гарантирует полный ответ при высокой задержке API или сети.
